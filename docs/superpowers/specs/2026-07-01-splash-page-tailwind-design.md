# Разводная страница + подключение Tailwind (prebuilt) — дизайн

Дата: 2026-07-01

## Контекст и цель

`olga-ko.com` — статический сайт-портфолио на GitHub Pages (деплой «из ветки», без
серверной части и без сборки). Сейчас корневой `index.html` просто редиректит на
`portfolio-ru/`. Нужна **разводная (хаб) страница** со списком ссылок на разделы, а также
внедрение стилей **Tailwind** — так, чтобы всё работало на статик-хостинге и шрифт везде
был **Inter** с едиными параметрами.

## Решения (согласовано с пользователем)

- **Tailwind:** prebuilt статический CSS. Собираем локально через Tailwind CLI (Node 24
  установлен) в минифицированный `tailwind.css` с только используемыми классами и
  коммитим. Никакого runtime-JS, никакого билд-шага на хостинге.
- **Объём сейчас:** Tailwind применяем **только к разводной странице**. Существующие
  страницы (портфолио, кейсы, md-страницы) не трогаем — миграция на Tailwind отдельными
  задачами позже.
- **Макет разводной:** вариант **A** — минимальный центрированный список.
- **cat-in-cap:** вливаем рабочие файлы папки в основной репозиторий (удаляем вложенный
  `cat-in-cap/.git`), ссылка ведёт на локальную `/cat-in-cap/`. Осознанный компромисс:
  +~226 МБ в репо (в основном `images/`). Историю `.git` (212 МБ) не вливаем.
- **Иллюстрация:** активная ссылка на существующую `/illustration/` как есть.

## Разводная страница (новый корневой `index.html`)

Заменяет текущий редирект — `olga-ko.com` показывает хаб.

- Центрированная колонка (~max-w-xl), вертикально по центру вьюпорта.
- Шапка: «Ольга Коновалова» + подпись «Product Designer, UX/UI дизайнер».
- 5 строк-ссылок с hairline-разделителями и индикатором `→` (hover: акцентный цвет):
  1. Портфолио → `portfolio-ru/`
  2. Большая библиотека Контура → `big-library/`
  3. Каллиграфия и леттеринг → `calligraphy-and-lettering/`
  4. Иллюстрация → `illustration/`
  5. Старый блог cat-in-cap.ru → `cat-in-cap/`
- Шрифт **Inter** через `https://rsms.me/inter/inter.css` (как на остальном сайте).
- Акцент — фирменный фиолетовый `#6753e6` (совпадает с `--p-primary` портфолио), текст `#222`.
- Адаптив: те же строки на мобильном, тап-таргеты ≥44px.
- Тот же счётчик Yandex.Metrika (id 95434312), что и на остальных страницах.

## Tailwind: интеграция (prebuilt)

- Версия: Tailwind **v4** (CSS-first конфиг).
- `package.json` — devDependency `tailwindcss` + `@tailwindcss/cli`, скрипты:
  - `build:css` — сборка минифицированного `tailwind.css`
  - `watch:css` — режим разработки
- Вход: `styles/tailwind.src.css`:
  - `@import "tailwindcss";`
  - `@theme` с токенами: `--font-sans: 'Inter', sans-serif;`, фирменные цвета
    (`--color-brand: #6753e6`, `--color-ink: #222` и т.п.).
  - `@source` указывает на `index.html`, чтобы сканировались используемые классы.
- Выход: `tailwind.css` (в корне, коммитим). Разводная линкует его `<link>`-ом.
- `node_modules/` добавляем в `.gitignore`.

## Изменения структуры проекта

- Новые файлы: `package.json`, `styles/tailwind.src.css`, `tailwind.css` (билд),
  новый корневой `index.html` (splash), обновлённый `.gitignore`.
- `cat-in-cap/`: удалить вложенный `.git`, файлы становятся частью репо.
- Незакоммиченная приборка из предыдущей задачи (переменные, дедуп и т.д.) — независима,
  не затрагивается.

## Проверка (end-to-end)

1. `npm run build:css` собирает `tailwind.css` без ошибок; файл содержит используемые классы.
2. Локальный сервер (`python3 -m http.server`), открыть `/` — рендер разводной, шрифт Inter,
   фиолетовый акцент применяются.
3. Все 5 ссылок резолвятся (HTTP 200): `portfolio-ru/`, `big-library/`,
   `calligraphy-and-lettering/`, `illustration/`, `cat-in-cap/`.
4. Консоль браузера без ошибок (кроме внешней Метрики, если нет сети).
5. Скриншот разводной для визуальной проверки.

# Блог Ольги Коноваловой — статичный архив

Архив блога «Моя жизнь в словах и картинках» (движок E2/Aegea),
сконвертированный в статичный сайт без серверной части.

## Структура

- `posts/*.md` — статьи в Markdown: frontmatter (заголовок, дата, теги),
  текст и секция комментариев после маркера `<!-- comments -->`
- `posts.json` — индекс постов для клиентской навигации
- `images/` — картинки из постов
- `fonts/` — Inter (variable, woff2) — единственный шрифт проекта
- `index.html`, `app.js`, `style.css` — сайт:
  hash-роутинг (`#/post/...`, `#/tag/...`), поиск, сортировка,
  лента/список, собственный markdown-рендерер, светлая и тёмная темы
- `styleguide.html` — гайд стилей (цвета, типографика, элементы)

### Стилизация

Вёрстка — на **Tailwind CSS через Play CDN** (`<script src="cdn.tailwindcss.com">`,
конфиг инлайном в `<head>` каждой страницы). Цвета — палитра Tailwind: нейтральные
`slate`, акцент `sky`; пишутся прямо в разметке утилитами
(`bg-white dark:bg-slate-900`, `text-sky-700 dark:text-sky-400` и т.д.).

Play CDN — это Tailwind v3, где шкал `slate`/`sky` нет в нужном (v4) виде, поэтому
они заданы в конфиге точными `oklch`-значениями из доки Tailwind v4 (чтобы цвета
совпадали с документацией).

Тёмная тема — вариант `dark:` (`darkMode: "class"`). Класс `.dark` на `<html>`
ставит небольшой скрипт в `<head>`: по умолчанию — системная настройка, либо
ручной выбор из `localStorage` (кнопка ◐). `style.css` держит только то, что
утилитами не выразить: `@font-face`, `color-scheme`, типографику markdown-контента,
стейты `.active` и `::after` (там — те же `oklch` slate/sky).

`style.css`/`app.js` подключаются с версией (`?v=tw4`) — после правок поднимите
номер, чтобы у вернувшихся читателей не залип кэш.

Посты были извлечены из SQL-дампа блога скриптом `convert.py`
(см. историю git — сам дамп и скрипт удалены после конвертации).

## Локальный запуск

```sh
python3 -m http.server 8137
# открыть http://localhost:8137
```

## Хостинг

Рассчитано на GitHub Pages: только статичные файлы, все пути
относительные, роутинг через `location.hash` — работает и из
подкаталога `username.github.io/repo/`. Файл `.nojekyll` обязателен,
иначе Jekyll не отдаёт `.md`-файлы.
